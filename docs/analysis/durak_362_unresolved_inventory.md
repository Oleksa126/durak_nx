# Durak NX — Канонічний інвентар 362 Strong Symbols / 631 Relocation Sites

Цей документ є машинно згенерованою специфікацією всіх зовнішніх символів Android Bionic, необхідних для повного зв'язування чотирьох модулів Durak 25.0 (`libsqlite3.so`, `libmain.so`, `libunity.so`, `libil2cpp.so`) перед переходом до запуску конструкторів (E06b).

> **Методологія та верифікація:**
> - Обчислення інвентарю виконано безпосередньо з перевірених у пам'яті ELF-модулів (`MultiModuleLoader`) із перевіркою розмірів, SHA-256 та GNU Build-ID.
> - Типи символів (`STT_FUNC` / `STT_OBJECT`) автоматично звірені з `.dynsym` кожного ELF-модуля (359 функцій, 3 об'єкти даних: `__sF`, `stderr`, `stdout`).
> - Прототипи C ABI каталогізовані за заголовками **Android NDK r26b (API 24+ AArch64 Bionic sysroot)** і підлягають похвильовій компіляційній перевірці під час реалізації.
> - **Wave 1 (Safe Leaf Libc & Math)** очищена від усіх явних (`locale_t`, `mbstate_t`) та неявних (`LC_CTYPE`, `LC_NUMERIC`) locale-залежностей, а також від stateful RNG (`lrand48`/`srand48`) та буферизованих Bionic-функцій (`basename`).
> - Досяжність із конструкторів (`constructor_reachability`) має статус `unverified` до побудови статичного графа викликів (E06b).
